# Карманный бюджет

Учёт расходов и доходов с голосовым вводом, целями, лимитами и инвестициями.
Все данные хранятся в браузере вашего телефона. Ключ ИИ тоже хранится только на телефоне.

## Как опубликовать на GitHub Pages

1. Зайдите на github.com, нажмите **New repository** и назовите его, например, `budget`. Выберите **Public** и нажмите **Create repository**.
2. На странице репозитория нажмите **Add file → Upload files** и выберите все файлы из этой папки: `index.html`, `manifest.webmanifest`, `sw.js`, `.nojekyll`, три `.png` и этот README. Нажмите **Commit changes**. Если в репозитории остались файлы от прошлых версий (`icon-180.png`, `icon-512-round.png`), их можно удалить.
3. Откройте **Settings → Pages**. В поле **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ-ЛОГИН.github.io/budget/`.

## Как поставить на iPhone как приложение

Откройте адрес в Safari, нажмите «Поделиться», затем «На экран „Домой“». Приложение откроется во весь экран, без адресной строки.

## Первый запуск

- **ИИ:** откройте Счета → ИИ, вставьте API-ключ и нажмите «Сохранить». Сервис определится по ключу сам: Gemini, OpenAI, Anthropic, OpenRouter. Для DeepSeek и других сервисов выберите его в списке вручную. Модель подбирается автоматически.
- **Перенос старых записей:** Счета → Данные → Импорт данных, выберите файл `budget-backup.json`.
- **Резервная копия:** время от времени делайте Счета → Данные → Экспорт данных. Если очистить данные Safari, записи пропадут.

## Цены активов

Цены подтягиваются при открытии приложения и по кнопке «Обновить цены»:
- акции и фонды Мосбиржи — с Мосбиржи;
- валюта — по курсу ЦБ РФ;
- криптовалюта — с CoinGecko.

Для иностранных акций и металлов укажите цену вручную.

## Важно

Файл с копией ваших записей (`budget-backup.json`) **не загружайте** в репозиторий: публичный репозиторий видят все. Импортируйте его прямо в приложении на телефоне.
